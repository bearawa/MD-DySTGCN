# 学位论文插图目录

协议：horizon-1（下一 4 小时时刻）、评估断面宗关、标准化空间 MAE/RMSE、反标准化 MAPE。  
数据来源：`data/comparison_metrics.json` 与 `data/runs/<模型>/`。  
复现：`python 论文插图包/code/visualize_ch3.py && python 论文插图包/code/plot_schematic.py && python 论文插图包/code/plot_thesis_figs.py`；经典基线需先 `python 论文插图包/code/train_classic_baselines.py`。
